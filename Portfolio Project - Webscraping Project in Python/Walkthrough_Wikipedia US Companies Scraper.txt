Wikipedia US Companies Scraper

Portfolio Project — Web Scraping + Data Extraction with Python

A clean and efficient web scraper that extracts the list of the 100 largest publicly traded companies in the United States by revenue from Wikipedia.

Project Goal

To scrape structured data from a real-world dynamic webpage (Wikipedia), transform it into a clean pandas DataFrame, and present it in a formatted view.

Final Output

- 100 rows × 7 columns** DataFrame
- Columns: `Rank`, `Name`, `Industry`, `Revenue (USD millions)`, `Revenue growth`, `Employees`, `Headquarters`
- Clean, well-structured data with proper indexing

Technologies Used

- Python
- requests
- BeautifulSoup4
- pandas
- Jupyter Notebook

Process Walkthrough

1. Accessing the Website
- Sent HTTP request with a custom `User-Agent` header to respect Wikipedia’s robot policy and avoid being blocked.

2. Locating the Correct Table
- Used `soup.find('table', id='mwOw')` to precisely target the main public companies table.
- Avoided fragile methods like `find_all('table')[n]` for better reliability.

3. Data Extraction
- Extracted column headers using `find_all('th')`.
- Iterated through all data rows (`<tr>`) and extracted cell content (`<td>`).
- Implemented checks to ensure proper column alignment.

4. DataFrame Creation & Cleaning
- Created a pandas DataFrame with correct column names.
- Cleaned text data using `.strip()`.
- Converted `Rank` to integer.
- Reset index for clean presentation.

5. Result
Successfully produced a clean, structured dataset ready for analysis or export.

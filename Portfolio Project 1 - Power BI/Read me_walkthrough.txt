Data Transformation
1. Row deletion of Column Browser, Os, City, Country and Referrer.
2. Split by delimiter on ( for 'Which Title Best Fits your Current Role?', 'What Industry do you work in?', and 'Which Country do you live in?' column, so that we dont get 50 different roles for Other. The specified Roles for Other is now in its own column next to it.

Did also do the same with the column called ' Favorite Programming Language' based on colon to standardize the answers.

3. Next is to turn a range of salary to an average for the column 'Current Yearly Salary (in USD)'.
Here I did first duplicate the column to experiment with and did split the columns where I replaced values such as +, k with nothing.

4. Created a new custom column with the following formula to get Average Salary from the modified columns from step 3:
([#"Q3 - Current Yearly Salary (in USD) - Copy.1"] + [#"Q3 - Current Yearly Salary (in USD) - Copy.2"]) / 2.

Once completed, I deleted the old modified columns where only Average Salary Column remains.

As there's probably more to do, I decided to limit the transformation as I got what I needed for my dashboard, and with my new data.

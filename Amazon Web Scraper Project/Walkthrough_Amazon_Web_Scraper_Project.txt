Amazon Product Web Scraper

Project Description:
I built a program that automatically collects information from Amazon product pages. The goal was to extract key details such as the product name, price, rating, and number of customer reviews.

What the program does:
- Finds and extracts the full product title
- Retrieves the current price including currency (e.g. EUR 92.04)
- Collects the star rating (e.g. 5.0) and how many people have reviewed the product
- Saves all the information neatly into a CSV file in my Downloads folder

Technologies Used: Python in Jupyter Notebook, BeautifulSoup, Requests, Regex, CSV, Web Scraping, Data Extraction

Key Skills Demonstrated:
- Ability to work with real websites that frequently change their layout
- Problem-solving when facing technical challenges (such as Amazon’s security measures)
- Writing clean and reliable code that produces useful results
- Automatically exporting data to a spreadsheet file for easy use
